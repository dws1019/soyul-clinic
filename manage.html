본문 바로가기
소율한의원 관리 도우미진료시간·공지·질문 등을 고치고 새 파일을 내려받습니다 홈페이지 보기

    이렇게 사용하세요

    1. 아래에서 내용을 고칩니다

      고친 내용은 이 화면 안에서만 바뀌며, 저장 버튼을 누르기 전까지 홈페이지에는 아무 영향이 없습니다.

    2. ‘새 파일 내려받기’를 누릅니다

      soyul-data.js 파일이 내려받아집니다.

    3. 홈페이지의 같은 이름 파일과 바꿉니다

      내려받은 파일을 assets/js/soyul-data.js 자리에 덮어쓰면 모든 페이지에 반영됩니다. 자세한 방법은 맨 아래 ‘홈페이지에 올리는 방법’을 보세요.

    이 화면에는 비밀번호가 없지만, 여기서 고친 내용이 홈페이지에 저절로 올라가지는 않습니다. 파일을 바꿔 올릴 수 있는 사람만 홈페이지를 바꿀 수 있습니다.

    홈페이지에 올리는 방법

    1. GitHub 저장소를 엽니다

      로그인한 뒤 저장소의 assets/js 폴더로 들어갑니다. 저장소 열기

    2. 파일을 올립니다

      오른쪽 위 Add file → Upload files를 누르고, 내려받은 soyul-data.js를 끌어다 놓습니다.

    3. 저장합니다

      아래쪽 초록색 Commit changes 버튼을 누릅니다. 1~2분 뒤 홈페이지에 반영됩니다.

    바뀐 내용이 바로 보이지 않으면 새로 고침(Ctrl+F5)을 해 보세요. 컴퓨터의 홈페이지 폴더에도 같은 파일을 덮어써 두면 다음에 헷갈리지 않습니다.

    고친 내용이 없습니다.
