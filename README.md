# 소율한의원 홈페이지

구의역 **소율한의원(素律)** 의 홈페이지입니다. 몸의 근본을 살피고, 나다운 리듬을 찾습니다. (2026년 12월 초 개원 예정)

- 사이트 주소: <https://dws1019.github.io/soyul-clinic/>
- 여러 페이지로 이루어진 정적 사이트(HTML · CSS · JavaScript)입니다. 이 저장소의 파일이 그대로 GitHub Pages로 배포됩니다.

## 페이지

| 메뉴 | 파일 | 내용 |
| --- | --- | --- |
| 첫 화면 | `index.html` | 이름의 뜻과 대표원장 사진, 세 클리닉, 대표원장, 지키는 것, 문을 열기까지(개원일기), 자주 묻는 질문, 오시는 길 |
| 소율 소개 | `about.html` | 이름의 뜻(素律), 대표원장이 만들고 싶었던 진료, 지키는 것, 심볼 |
| 의료진 소개 | `doctor.html` | 오지현 대표원장 사진·인사말·약력 |
| 진료 안내 | `clinic.html`, `clinic/*.html` | 귀 질환 클리닉(증상 6가지 상세, 자가 체크) · 척추·통증 클리닉(추나요법) · 비만·체형 클리닉, 치료 방법 |
| 공간 | `space.html` | 준비하는 모습(위치·공사 사진), 자리를 고른 까닭, 장비 |
| 소율 이야기 | `story.html` | 블로그 글(카테고리별로 골라 보기), 채널 |
| 이용 안내 | `guide.html`, `faq.html` | 진료시간, 예약·첫 방문, 비용, 자주 묻는 질문 |
| 오시는 길 | `location.html` | 약도, 지도 앱 길찾기, 대중교통, 주차 |
| 그 밖 | `privacy.html`, `404.html`, `manage.html` | 개인정보처리방침, 없는 주소 안내, 관리 도우미 |

## 자주 바꾸는 내용은 한 파일에

진료시간·휴진일·공지·예약 주소·자주 묻는 질문·비급여 진료비·공간 사진처럼 자주 바뀌는 내용은
모두 **`assets/js/soyul-data.js`** 한 파일에 있습니다. 이 파일만 바꾸면 모든 페이지에 반영됩니다.

직접 고치기 어렵다면 **관리 도우미**를 쓰세요.

1. <https://dws1019.github.io/soyul-clinic/manage.html> 을 엽니다.
2. 화면에서 내용을 고치고 **새 파일 내려받기**를 누릅니다.
3. 내려받은 `soyul-data.js`를 이 저장소의 `assets/js` 폴더에 올립니다. (Add file → Upload files → Commit changes)

1~2분 뒤 홈페이지에 반영됩니다.

| 항목 | 설명 |
| --- | --- |
| `clinic.openDate` | 개원일(YYYY-MM-DD). 비워 두면 `openLabel` 문구가 보이고, 날짜를 넣으면 그날부터 실시간 진료 상태가 표시됩니다 |
| `hours` | 평일·토일공휴일 진료시간, 점심시간, 휴진 요일, 공휴일·임시 휴진일 |
| `channels` | 네이버 예약·카카오톡 채널·블로그·인스타그램 주소. 비어 있으면 ‘준비 중’으로 표시 |
| `notice` | 맨 위 공지 띠. 비워 두면 숨김 |
| `faq` | 자주 묻는 질문 (분류, 첫 화면 표시 여부) |
| `fees` | 비급여 진료비 표 |
| `photos` | 공간 사진 (첫 번째 사진은 첫 화면에도 쓰임) |
| `posts` | 블로그 글 목록 (카테고리·날짜·한두 줄 소개) |
| `hero.video` | 첫 화면 영상 (비워 두면 사진) |

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `assets/js/soyul-data.js` | 운영 정보 (위 설명) |
| `assets/js/soyul-render.js`, `soyul.js` | 운영 정보를 화면에 그리는 기능, 메뉴·예약 창·지도 연결 |
| `assets/css/soyul.css` | 화면 디자인 (주조색 SOYUL BROWN 하나, 리디바탕 + 고운돋움) |
| `assets/img/` | 로고(CI), 원장 사진, 위치·공사 사진, 공유 이미지 |
| `assets/fonts/` | 리디바탕 · 고운돋움 · Noto Serif KR(한자 두 글자) 웹폰트 — SIL OFL 1.1 |

페이지 문구나 디자인을 크게 바꿀 때는 빌드 원본(`소율한의원_홈페이지_빌드원본.zip`, 저장소 밖에 보관)에서 고친 뒤
`node build.mjs`로 다시 만들어 올립니다. 문구 한두 곳은 해당 `.html` 파일을 직접 고쳐도 됩니다.

## 참고

- 공간 사진은 블로그에 올린 위치·공사 사진(갈색 한 톤)입니다. 공사가 끝나면 실제 공간 사진으로 바꿔 주세요.
- 비급여 진료비와 개인정보처리방침의 위탁업체는 개원 전에 채워야 합니다.
- 진료 안내의 연구 요약과 인사말·소개 글은 게시 전 대표원장의 검수를 권합니다.
- 도메인을 연결하면 주소가 바뀌므로, 빌드 원본의 사이트 주소를 바꿔 다시 빌드해야 공유 이미지·검색엔진용 주소가 맞습니다.
- 글꼴 라이선스는 `assets/fonts/OFL.txt`, 아이콘 라이선스는 `NOTICE.txt`에 있습니다.
